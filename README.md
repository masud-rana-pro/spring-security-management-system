# Secure Auth Lab

A simple full-stack authentication learning project using Spring Boot, Spring Security, JWT, OAuth2, CORS, and Angular.

## Project Goal

This project is built for learning and practicing authentication and authorization in a real full-stack application.

## Tech Stack

### Backend

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- JWT
- OAuth2 Client

### Frontend

- Angular
- TypeScript
- SCSS
- Route Guard
- HTTP Interceptor

### Tools

- Git
- GitHub
- Postman
- MySQL Workbench

## Main Features

- User Registration
- User Login
- JWT Token Authentication
- Protected API
- Role Based Authorization
- CORS Configuration
- Google Social Login
- GitHub Social Login
- Angular Auth Guard
- Angular JWT Interceptor
